Pexeso

My first game. JavaFX. My pictures from the forest.

About the game

Pexeso Forest is a classic memory game for one or two players. The images used in the game are my own photos taken during walks in the forest.

Game features

  • fast and simple gameplay
  • one point for a correct pair, minus one point for a wrong pair
  • improving your score
  • original visual style

The game is currently available as a Windows download. A web version is in development.
